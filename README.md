# جدول تک حذفی 🏆

اپلیکیشن اندرویدی مدیریت حرفه‌ای تورنمنت‌های تک‌حذفی — کاملا آفلاین، فارسی و راست‌چین.

## قابلیت‌ها
- ساخت تورنمنت (۴ تا ۶۴ تیم) با رشته‌های مختلف
- ثبت تیم/بازیکن + افزودن گروهی
- قرعه‌کشی تصادفی / سیدی / دستی + مدیریت BYE + جابجایی دستی
- جدول گرافیکی با زوم، صعود خودکار، رده‌بندی، انصراف/حذف انضباطی، پنالتی
- زمان‌بندی بازی‌ها، آمار و جدول عملکرد، خروجی عکس PNG و چاپ/PDF، بکاپ JSON

## اجرا در مرورگر
کافیست `www/index.html` را باز کنی.

## بیلد APK
بیلد به‌صورت خودکار با GitHub Actions انجام می‌شود:
۱. پوش به برنچ `main`
۲. دانلود فایل APK از بخش Artifacts ورک‌فلو «Build APK»

ساخت دستی: `npx cap sync android` سپس `./gradlew assembleDebug` داخل پوشه `android`.
